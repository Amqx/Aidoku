# Aidoku
This fork will have a couple UI/ UX changes that I have made for personal preference. 

### What's new:

- Removed the dictionary OCR stuff
- Added a custom compact list library format that's similar to Tachi's list for familiarity
- Google Drive backup auto uploadingi
- Custom backup format that quarters backup sizes
    - This format is incompatible with upstream. If you need to move back to upstream's format
       get an AI or something to go through the format and write a converter for you.

## Installation

You have to sideload it. I'm not providing unsigned binaries either so go build it yourself with XCode or ask AI to write a workflow for you to build one.

## Stability
I highly recommend you use [upstream](https://github.com/Aidoku/Aidoku) if you want a more stable experience. This fork of mine may have
changes that aren't as well tested, resulting in instability.
